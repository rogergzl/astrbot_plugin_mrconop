## 三、核心架构分析

### 1. 插件主类 `MrconPlugin(Star)`
- 继承 `Star`，接受 `context: Context` 和 `config: AstrBotConfig`
- 使用 `@register` 装饰器（规范中标注为已废弃，当前版本自动识别）
- 实现了 `initialize()`（启动后台任务、Web 面板）和 `terminate()`（清理）

### 2. 功能模块（全部在 main.py 中）

| 模块 | 命令 | 说明 |
|------|------|------|
| **MC 服务器查询** | `/mc`, `/mcget`, `/mclist`, `/mcadd`, `/mcdel`, `/改服`, `/共享服`, `/清理服` | 分群管理 MC 服务器列表，mcstatus 查询状态 |
| **RCON 远程命令** | `/mrcon`, `/选服`, `/宏`, `/脚本` | 通过 `transport.rcon_command()` 转发到 MC |
| **投票系统** | `/rc赞同`, `/rc反对`, `/rc通过`, `/rc否决` | 公共命令投票裁决（阈值/平票策略/管理员裁决） |
| **在线时长追踪** | `/在线时长`, `/在线提醒` | 后台轮询在线玩家，记录会话，支持提醒+超时踢出+封禁 |
| **玩家数据库** | `/绑定`, `/签到`, `/我的`, `/理赔`, `/同意理赔`, `/拒绝理赔` | SQLite 存储绑定/积分/签到/补偿审批 |
| **群服消息互联** | `/msay`, `/消息互通` | 使用 RCON `tellraw` 转发群消息到 MC 公屏 |
| **帮助** | `/rchelp` | 完整命令帮助 |

### 3. 数据流

```
QQ 群消息 → filter.command 路由 → 权限检查(is_allowed) → 速率限制(_check_rate)
  → RCON 连接(transport.py) → 审计日志(audit.log)
  → 响应返回群聊
```

```
后台定时任务 → _online_tracker_loop() → RCON list 获取在线玩家
  → 记录会话(SQLite) → 超时提醒/踢出/封禁
```

### 4. 数据持久化
- **SQLite** (`mrcon.db`)：players / online_sessions / compensations
- **JSON** (`mcserv_{群号}.json`)：分群 MC 服务器列表
- **JSONL** (`audit.log`)：RCON 审计日志
- 数据目录：`data/plugin_data/mrcon/`（符合规范要求）

## 五、总结

这是一个功能非常丰富的 MC 综合管理插件，架构清晰但有改进空间：
- **代码组织**：建议将 main.py 按模块拆分（查询/RCON/追踪/玩家/互联 各自独立文件）

- **Web 面板 bug**：`Database.execute()` 不存在，需修复
- **配置持久化**：Web 面板修改配置后需确保重启不丢失
