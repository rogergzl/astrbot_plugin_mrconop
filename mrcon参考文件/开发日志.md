# 开发日志

> 记录本项目的关键变更，作为开发追溯与迭代复盘依据。按时间倒序排列。

---

### 2026-06-09 | v3.47.0 | lindagao

- **变更类型**：功能新增
- **涉及模块**：`core/database.py`、`main.py`、`requirements.txt`、`metadata.yaml`、`README.md`
- **变更详情**：
  - 新增 `ExternalMySQLDB` 类（`core/database.py` L670-L1120），使用 `pymysql` 驱动实现 MySQL 外部数据库支持，提供与 `ExternalSQLiteDB` 同构的接口
  - `ExternalMySQLDB` 覆盖在线状态（`online_state`）与在线会话（`online_sessions`）两张表的 CRUD，支持读写分离和双写模式
  - 更新 `Database.configure_external()` 方法，`mysql` 类型从预留占位改为实际实例化 `ExternalMySQLDB`
  - 重构 `add_online_session()`、`get_online_sessions()`、`get_player_sessions()` 为 impl 委托模式（`_*_impl`），统一 Database / ExternalSQLiteDB / ExternalMySQLDB 三类数据库的调用接口
  - 更新 `Database` 类和 `ExternalSQLiteDB` 类，补全 `_add_online_session_impl`、`_get_online_sessions_impl`、`_get_player_sessions_impl` 三个 impl 方法
  - 更新 `main.py` 外部数据库触发条件，支持 `ext_type == "mysql"` 时自动连接（无需 `ext_db_path`）
  - 版本号按 SemVer 升级：v3.46.7 → v3.47.0（次版本号 +1，修订号置 0）
- **补充备注**：
  - MySQL 为可选依赖，使用前需 `pip install pymysql`
  - 配置方式：`online_db_ext_type` 设为 `mysql`，填写 `host/port/user/password/database` 字段
  - 向后兼容：未配置 MySQL 时项目行为与旧版完全一致，默认使用本地 SQLite
