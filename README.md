RCON 命令转发 + 服务器并发查询 + 玩家数据库 + 在线时长追踪 + 签到积分 + 物品补偿 + 积分兑换商城 + 抽奖系统 + 群服消息双向互联 + 日志事件宏 + 全功能 Web 管理面板

## 安装

作为 AstrBot 插件直接加载，依赖 `mcstatus`（首次运行自动安装）。

```
pip install mcstatus Pillow
```

`Pillow` 可选，安装后「在线列表渲染为图片」功能可用。

## 功能概览

### MC 服务器查询

- 查询所有服务器状态（版本/延迟/在线玩家/Mod列表）
- 单个服务器详情查询
- 查询显示项可配置（地址、版本、延迟、在线数、玩家详情）
- 失效服务器自动清理（可配置天数）
- 支持服务器跨群共享

### RCON 远程命令

- 群聊转发 RCON 命令到 MC 服务器，黑白名单 + 公开命令控制
- 服务器选择、命令投票（赞同/反对 + 管理员裁决 + 平票策略）
- 宏命令系统：预设 RCON 命令模板 + 开关控制
- Python 脚本执行：上传/热加载/开关控制
- 自定义命令映射：`/rc自定 <别名>` → 服务器预设命令
- 危险命令黑名单（stop/restart/op/deop 等）
- 智能速率限制：动态递增间隔 + 白名单 + 自动恢复

### 群服消息互联

三种转发方式互补：

| 方式 | 方向 | 延迟 | 依赖 | 适用场景 |
|------|------|------|------|----------|
| RCON tellraw | 群→服 | <0.1s | RCON | 群消息实时显示到 MC 公屏 |
| MC 模组 | 服→群 | <0.1s | MC 插件/模组 | 服内聊天实时转发到群 |
| 日志监听 | 服→群 | ~0.5-1s | 无 | 无需模组，变相实现服→群转发 |

- `/msay` 主动发送消息到 MC 公屏
- `/消息互通` 按群独立配置（开关/方向/格式/前缀/目标服务器）
- 全局/分群/独立三种模式
- 日志类型前缀自定义（聊天/命令/死亡/PVP死亡/进出/成就/系统）
- 转发格式支持 `{name}`/`{msg}`/`{player}` 占位符
- 自动从服务器管理绑定的群号识别转发目标，无需额外配置
- 事件去重防重复转发（5 秒窗口）
- 群聊名称自动从服务器管理读取，各处统一显示别名

### 日志监听 + 事件宏

通过读取 MC 服务器 `latest.log` 实时监控游戏事件，并自动触发预设 RCON 命令：

- **12 种日志事件**：玩家聊天、命令、死亡（环境/实体/PVP/kill/虚空等）、进出、成就、重生、传送、踢出、世界进入、服务器启停
- **事件宏编辑器**（Web 面板可视化）：条件组匹配（服务器/事件类型/玩家正则）、冷却时间、频率限制、在线时长条件
- **变量替换**：`{player}`/`{PLAYER}`/`{mc_id}`/`{qq}`/`{server}`/`{event_type}`/`{event_param}` 自动从数据库获取
- `say`/`tell`/`msg` 命令自动转换为 `tellraw`，移除 Minecraft 默认前缀
- 游戏内通知支持颜色码 `§a绿 §b青 §c红 §e黄 §l粗体`
- 日志读取位置持久化（重启不丢事件）

### 在线时长追踪

- 三种轮询模式：RCON 命令 / smart 智能 / MCStatus 查询
- 群内时长排行 `/在线时长`
- 游戏内提醒（可配置多级提醒时间）
- 超时自动踢出 + tempban（MC 原生封禁，插件重启不丢失）
- `/在线提醒` 按群覆盖配置（提醒/踢出/@通知/阈值/封禁时长/原因模板）
- 支持累计模式和单次模式
- 排行数据可手动重置或按时间窗口自动重置
- 封禁命令模板支持 `{player}`/`{minutes}`/`{reason}` 占位符

### 玩家系统

- **绑定**：QQ → MC ID 绑定，注册即送积分
- **签到**：每日签到得积分，连续签到额外奖励
- **VIP 等级**：VIP 玩家可配置专属事件宏（进出/死亡/在线等）
- `/我的` 查看个人积分、签到统计、VIP 信息

### 补偿系统

- `/理赔` 提交物品补偿申请（RCON 命令形式）
- 管理员 `/理赔列表` 审核 → `/同意理赔` 自动执行 RCON → `/拒绝理赔`
- 支持全局模式（所有人可申请）和白名单模式
- Web 面板待处理/已通过/已拒绝分类管理

### 积分商城 + 抽奖

- **兑换商城**：按群配置兑换项，消耗积分换物品（自动 RCON 执行）
- **抽奖系统**：按群配置奖品池（概率/数量/消耗积分/RCON 命令），支持兑奖

## Web 管理面板

基于原生 HTTP 服务器（零外部依赖），PBKDF2-SHA256 密码认证，暗色主题，端口 `9949` 可配置。
